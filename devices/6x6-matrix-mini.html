Before flashing

A few practical checks save a lot of retries.

Use a computer for flashing The browser installer needs desktop Chrome or Edge, HTTPS or localhost, and Web Serial.
Use a USB data cable A charge-only cable can power the board without exposing its serial port.
Close serial tools Close Arduino Serial Monitor and any other program already using the controller port.
Disconnect the Pico TX line For a direct ESP8266 upload, disconnect Pico GP0 TX from ESP RX / GPIO3 first.

Main controller

Flash the ESP8266 with the Firmware button held.

The web installer uses the same complete binary builds that are stored in the site's firmware folders. Older builds remain available for rollback and testing.

  1. Connect the main controller to the computer by USB.
  2. Find the red-and-black inline Firmware button between the Pico TX line and the ESP RX line.
  3. Hold Firmware, choose a build below, and select the LumiCon serial device when prompted.
  4. Keep holding the button until the install completes.
  5. Release the button and allow the controller to reboot.
  6. If flashing fails, unplug the 6x6 keypad and try again.
Recovery: the installer may offer to erase the device. Use that for a clean recovery only; it can remove saved Wi-Fi settings and pet data.

Phone-first Wi-Fi setup

Use your mobile phone for the captive portal.

The controller's temporary setup network is designed to be completed from a phone. A desktop browser often stays on the normal network and misses the device portal.

  1. Power the controller and wait for the setup prompt.
  2. On your phone, open Wi-Fi settings and join Lumi-Con-Setup.
  3. Tap the phone's Wi-Fi sign-in notification. If it does not appear, open the phone's browser and visit http://192.168.4.1.
  4. Select your normal home or streaming Wi-Fi network and enter its password.
  5. Save the settings, then note the controller IP shown on the TFT after it reconnects.
Need to start again? Hold Pico key K0 at boot to clear saved Wi-Fi and reopen phone setup. K0 is the top-left key; K35 is the bottom-right key.

Lumia connection

Turn the hardware into stream actions.

Install the current plugin package from the device repository, then configure the host after phone Wi-Fi setup has completed.

Plugin defaults

  • Enable Listener: on
  • Listen Port: 8787
  • ESP Base URL: the IP shown on the TFT
  • Shared Secret: blank unless you set one in firmware
Open current plugin files ->

Register the PC

From a browser on the same network, open:

http://<device-ip>/plugin?host=<pc-ip>

This stores the computer address used by the controller to send key events to Lumia.

Available actions

Display: Add Line, Display: Set Status, Display: Clear, Display: Celebration, Device: Connect, Device: Screen Mode, and Pet Action.

Useful variables

{{event}} {{kind}} {{key_label}} {{device_ip}} {{device_rssi}} {{device_status_text}} and the pet state variables are available to Lumia.

Build reference

The useful details, in one place.

The figures below are taken from the LumiCon 6x6 Mini device repository and its current firmware notes.

Architecture and wiring

The Pico scans the 6x6 matrix and sends packets over UART to the ESP8266. The ESP8266 drives the ST7735 TFT, joins Wi-Fi, serves the local API, and posts events to Lumia.

  • Rows: GP12, GP1-GP5
  • Columns: GP6-GP11
  • Pico TX: GP0 to ESP RX / GPIO3
  • TFT: SCK D5, MOSI D7, CS D2, DC D1
Boot keys and modes
  • K0: clear Wi-Fi and open phone setup
  • K1: Chat mode
  • K2: noPet diagnostics
  • K35: virtual pet mode
  • Runtime modes also include LCD Only Mode.
Local HTTP API

The current firmware exposes /msg, /status, /clear, /ui, /health, /plugin, /celebrate, /mode, and /pet.

Use the device IP after Wi-Fi setup. These routes are local network tools for testing, integrations, and the Lumia plugin.
