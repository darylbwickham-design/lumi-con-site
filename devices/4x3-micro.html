Setup flow

Flash, connect, then configure Lumia.

Use a computer for the USB firmware install. Use a mobile phone for the controller's first Wi-Fi connection, then finish the Lumia pairing on the local network.

Computer

1. Flash the controller

Use Chrome or Edge, a USB data cable, and the inline Firmware button while installing the ESP8266 build.

Mobile phone

2. Join setup Wi-Fi

Connect your phone to Lumi-Con-Setup, tap the sign-in notification, or visit http://192.168.4.1 in the phone's browser.

Same network

3. Pair the plugin

Use the device IP and configure the Lumia plugin on the computer that will receive key events.

Before flashing

Check the cable and serial connection.

Desktop Chrome or Edge The web installer needs Web Serial and a secure page or localhost.
USB data cable Charge-only cables will not expose the controller to the installer.
Close serial tools Arduino Serial Monitor and other serial tools must release the port.
Hold Firmware Keep the inline Firmware button held until the install has finished.

Main controller

Install the ESP8266 build.

Choose the current build for a normal update. The folder list keeps older files available where the repository provides them.

  1. Connect the controller to the computer by USB.
  2. Hold the inline Firmware button.
  3. Choose a build below and select the serial device when prompted.
  4. Keep holding the button until the install completes, then release it.
  5. If the install fails, disconnect the keypad and retry.

Flash the Pico

  1. Unplug the keypad board.
  2. Hold BOOTSEL while connecting USB.
  3. Open the RPI-RP2 drive.
  4. Copy the UF2 file onto it and wait for the automatic reboot.
