Satisfactory Plus Setup

Install SF+ on Steam build 517554 with the pinned mod set, a separate save folder, and a desktop shortcut.

Download for Windows (.zip)

Windows 10 or 11 (64-bit) · Steam account that owns Satisfactory

Get started

  1. Open the installer

    Extract the ZIP, then open SFPlus-Setup.exe from the extracted folder.

  2. Choose an install folder

    Pick an install folder and choose whether to include Factory Live and copy your saves. Click Copy beside the Steam command, then Install SF+.

  3. Start the Steam download

    If Steam opens its Console tab, paste the command and press Enter. Setup takes over when Steam says Depot download complete. Allow about 60 GB if the Steam download and separate install share a drive.

  4. Launch Satisfactory Plus

    Use the Satisfactory Plus desktop shortcut when setup finishes. With Factory Live selected, look for Satisfactory Plus - Factory Live. This copy stores saves in its own UserData folder.

Included versions

Satisfactory Plus 2026.3.489, Satisfactory Mod Loader 3.12.0, Infinite Zoop 1.11.2, RoadMaker 1.4.0, and the pinned libraries they need.

Optional Factory Live 0.9.8 for build 517554 adds stream integrations.

The pinned versions match the working manual SF+ installation. A full Steam download and first launch through the installer are pending verification.
