Factory Live Chaos for Satisfactory

1. Use the Steam build 517554 with SML 3.12. Close the game. Extract the Windows
   mod ZIP into FactoryGame\Mods\FactoryLive in the game installation. Check that
   FactoryLive.uplugin is directly inside the FactoryLive folder.
2. Install Node.js 22 or later from nodejs.org. In the Bridge folder, double-click
   Start Factory Live Bridge.cmd and leave the window open. It starts disarmed.
3. In Lumia 9.4, open Settings > Plugins > Installed > Install Manually and choose
   the included Factory Live Chaos .lumiaplugin file. Enable it if prompted.
4. Load a save as host. Use Arm Bridge on a private Lumia button or a broadcaster-
   only command. Use Disarm Bridge to pause viewer effects and clear queued work.
5. Add effects such as Spawn Hog or Drop Nobelisk to rewards. Under Alerts >
   Factory Live Chaos > Pioneer Death, set up the sound, overlay, or action you want.

If upgrading an existing setup, keep the same Lumia plugin edition, link file,
and local bridge config. The bridge reads bridge.local.json when present.
