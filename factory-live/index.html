Install and start

Windows preview. Start in a test save. Explosions can damage the pioneer and remove destructible scenery.

Upgrading from an older release? Close Satisfactory and replace the Windows mod. Stop the old bridge and start the new one from a fresh folder. Use the new config as the base for custom mappings and update your Lumia plugin in place. The local connection credentials carry over.

  1. Install the Windows mod

    With Satisfactory closed, turn on Mods in Satisfactory Mod Manager and enable Satisfactory Mod Loader 3.12 in the profile you’ll launch. In Steam, right-click Satisfactory and choose Manage → Browse local files. Extract the Windows mod ZIP into FactoryGame\Mods\FactoryLive in that folder. Check that the descriptor is directly inside FactoryLive.

    FactoryGame\Mods\FactoryLive\FactoryLive.uplugin

  2. Start the bridge

    Extract the bridge ZIP to a separate folder. Install Node.js 22 or later. Open the folder that contains bridge.mjs, type powershell into File Explorer’s address bar, and press Enter. Run the command below and leave that window open.

    node bridge.mjs serve

  3. Load your save and arm

    Launch Satisfactory through SMM and load your save. In a second PowerShell window in the bridge folder, check for connected: true and game.ready: true. Then run arm and choose a preset below.

    node bridge.mjs status
node bridge.mjs arm

    Once armed, you can try node bridge.mjs trigger turn-around while on foot in a test save. A bridge receipt confirms the request was queued.

  4. Stop events when you’re done

    Disarm to clear the queue and cancel undetonated drops. Living creatures and kill history are saved with the world.

    node bridge.mjs disarm

Pick an event

Choose the effect in Lumia or use the preset name in Streamer.bot or PowerShell. Large requests run in paced waves as the game has room.

node bridge.mjs trigger cluster-rain

Living creature waves share a 224-point budget. Hogs count as one point, and tougher creatures count for more. The game spaces out new spawns and pauses them when frame times rise.

Each random preset has a 60-second default cooldown. It picks one available effect and shares that effect’s cooldown and queue limits with direct triggers. You can edit the choices and cooldowns in your local bridge config.

Back up and restore your backpack

From the bridge folder, run these host commands while your save is loaded and unpaused. They also work with the bridge disarmed. Each save has its own snapshot and recovery copy for the host’s main backpack.

  1. Take a snapshot

    Capture backpack slots, quantities, and item state. Taking a new snapshot replaces the previous one. Save the game to keep it across reloads.

    node bridge.mjs inventory snapshot

  2. Check your backup

    See whether the host has a snapshot or recovery copy in the loaded save and check the result of the last operation.

    node bridge.mjs inventory status

  3. Restore the snapshot

    Clear the backpack and recreate the saved contents. Restore keeps a recovery copy of the contents it replaces, including items added after the snapshot.

    node bridge.mjs inventory restore

  4. Undo a restore

    Use the recovery copy to get back the backpack contents from just before the restore. Save the game to keep your new inventory state.

    node bridge.mjs inventory undo

Troubleshooting

Satisfactory reports a missing SML plugin

Enable Mods and Satisfactory Mod Loader 3.12 in the same SMM profile. Check that the Factory Live folder is named FactoryLive and the .uplugin file is directly inside it. Satisfactory manual install guide

The bridge says the game is disconnected or unready

Load a save as the host, unpause and regain control of your pioneer. Run node bridge.mjs status from the bridge folder. Arm the bridge again after a world change or lost heartbeat.

A webhook returns 401, 409 or 429

401 means the bridge rejected the token. 409 means the effect is unavailable or the game needs to be ready and armed. 429 means a cooldown, rate limit, queue cap or frame-time pause is active. Wait for capacity before retrying.

How can I check which mobs or drops appeared?

status reports the save’s mob counters and the session’s Nobelisk launches, impacts, expirations and cancellations. In the game console, use FactoryLive.Mobs to see individual records. The game logs are in %LOCALAPPDATA%\FactoryGame\Saved\Logs.

Restore says the snapshot is unavailable or incompatible

Use the same save and host account that made the snapshot. Check node bridge.mjs inventory status. A restore requires compatible slots for the saved stacks.
