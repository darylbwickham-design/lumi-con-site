Factory Live

Let Twitch chat spawn creatures, launch Nobelisk fireworks, or turn the Pioneer around in Satisfactory.

Get the Satisfactory mod Watch the demo

Windows Steam · Build 520140 with SML 3.12.1 · Build 517554 with chaos.16

Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. Keep Disarm Bridge on a private Lumia button. It clears queued effects; creatures already in the world stay there.

Install Factory Live

  1. Get the Mod Manager

    Install Satisfactory Mod Manager (SMM) and select your Steam installation.

  2. Install or update the mod

    Close Satisfactory. In SMM, select your play profile, switch Mods on, and search for FactoryLive Stream Integrations. For Steam build 520140, install 0.9.0-chaos.23 with SML 3.12.1. If you already have Factory Live, click Check for updates. For the older build 517554, choose chaos.16.

  3. Load a save

    Start Satisfactory and load a save as host. The bridge starts and arms automatically when the world is ready.

Manual downloads

  • Chaos.23 for Steam build 520140 · Includes the crowded-save respawn fix.
  • Chaos.16 for Steam build 517554

Install a compatible SML through SMM in your play profile, then close the game. In Steam, open Satisfactory’s Manage → Browse local files. Back up any existing FactoryGame/Mods/FactoryLive folder outside the Mods folder. Extract the ZIP’s FactoryLive folder into FactoryGame/Mods. You should see FactoryGame/Mods/FactoryLive/FactoryLive.uplugin. Switching SMM profiles can replace a manual installation.

Launch the game, load a save as host, then follow the guide for your streaming app. Try Turn Around first. If the Pioneer turns, your chat integration is reaching this world.

Connect your stream

  • Lumia Stream for ready-made chat commands and Twitch rewards.
  • Streamer.bot for your own commands, alerts, and rewards.
  • HTTP webhooks for other local tools.

Choose an effect

Spawn a single creature or a wave, drop Nobelisks, turn the Pioneer around, or make them drop equipment. See preset IDs.

If effects don’t start

Check that SMM has Mods on and the game’s Mods screen shows the version for your game build. Close any older standalone Factory Live bridge before restarting the game.
