Install and start

Preview build. Version 0.5.0 passed offline checks. Its gameplay is unverified. Start in a test save since the game’s explosions can damage the pioneer and remove destructible scenery.

  1. Install the Windows mod

    With Satisfactory closed, turn on Mods in Satisfactory Mod Manager and enable Satisfactory Mod Loader 3.12 in the profile you’ll launch. Extract the Windows mod ZIP into FactoryGame\Mods\FactoryLive under your Satisfactory folder. Check that the descriptor is directly inside the mod folder.

    FactoryGame\Mods\FactoryLive\FactoryLive.uplugin

  2. Start the bridge

    Extract the bridge ZIP to a separate folder. Install Node.js 22 or later, then open PowerShell in the bridge folder and run this command. Leave that window open.

    node bridge.mjs serve

  3. Load your save and arm

    Launch Satisfactory through SMM and load your save. In a second PowerShell window in the bridge folder, check for connected: true and game.ready: true. Then run arm and choose a preset below.

    node bridge.mjs status
node bridge.mjs arm

  4. Stop events when you’re done

    Disarm to clear the queue and cancel undetonated drops. Living creatures and kill history are saved with the world.

    node bridge.mjs disarm

Pick an event

Use the preset name in your terminal, webhook or Streamer.bot mapping. Large requests run in paced waves as the game has room.

node bridge.mjs trigger cluster-rain

Connect your stream

Run your stream tool and the bridge on the PC hosting Satisfactory. The bridge listens on 127.0.0.1:37128 by default. Use one mapping per command or reward when both tools are running.

Lumia Stream

  1. Add an API action to your chat command, alert or point redemption.
  2. Set the method to POST and the URL to http://127.0.0.1:37128/v1/trigger.
  3. Set Content-Type to application/json and Authorization to Bearer YOUR_WEBHOOK_TOKEN. The bridge creates your webhookToken in %LOCALAPPDATA%\FactoryLive\link.json on first start. Keep it on your PC.
  4. Paste this JSON as the request body. It follows the preset selected above.
{"preset":"cluster-rain"}

For a Custom JavaScript action, paste the template and set its preset and webhook token in Lumia’s editor.

Download the Lumia action Lumia action documentation

Streamer.bot

  1. In Servers/Clients → WebSocket Server, start the server on 127.0.0.1:8080. Create the chat commands you want under Commands.
  2. Make a copy of bridge.config.json named bridge.local.json. Set streamerBot.enabled to true and confirm the WebSocket URL is ws://127.0.0.1:8080/.
  3. Use streamerBot.commands to map exact chat commands to presets. Use streamerBot.rewards to map Twitch reward IDs. Stop any existing bridge with Ctrl+C, then start it with the new config and arm again.
node bridge.mjs serve bridge.local.json

If WebSocket authentication is enabled, set FACTORYLIVE_STREAMERBOT_PASSWORD in the same PowerShell session before starting the bridge.

$env:FACTORYLIVE_STREAMERBOT_PASSWORD = Read-Host "Streamer.bot WebSocket password" -MaskInput

For subs, cheers, hotkeys or other actions, paste the C# webhook template under Core → C# → Execute C# Code and set its Preset.

Troubleshooting

Satisfactory reports a missing SML plugin

Enable Mods and Satisfactory Mod Loader 3.12 in the same SMM profile. Check that the Factory Live folder is named FactoryLive and the .uplugin file is directly inside it. Satisfactory manual install guide

The bridge says the game is disconnected or unready

Load a save as the host, unpause and regain control of your pioneer. Run node bridge.mjs status from the bridge folder. Arm the bridge again after a world change or lost heartbeat.

A webhook returns 401, 409 or 429

401 means the bridge rejected the token. 409 means the effect is unavailable or the game needs to be ready and armed. 429 means a cooldown, rate limit, queue cap or frame-time pause is active. Wait for capacity before retrying.

How can I check which mobs or drops appeared?

status reports the save’s mob counters and the session’s Nobelisk launches, impacts, expirations and cancellations. In the game console, use FactoryLive.Mobs to see individual records. The game logs are in %LOCALAPPDATA%\FactoryGame\Saved\Logs.
