Factory Live

Let Twitch chat spawn creatures, launch Nobelisk fireworks, or turn the Pioneer around in Satisfactory.

Get the Satisfactory mod Watch the demo

Windows Steam · Builds 517554 and 520140 · SML 3.12.0 or compatible later version

Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. Keep Disarm Bridge on a private Lumia button. It clears queued effects; creatures already in the world stay there.

Install Factory Live

  1. Get the Mod Manager

    Install Satisfactory Mod Manager (SMM) and select your Steam installation.

  2. Add the mod

    Search for FactoryLive Stream Integrations. Select your play profile, switch Mods on, and install the compatible version SMM offers. Check Installed version before using the multiplier examples below. SMM handles the Satisfactory Mod Loader dependency.

  3. Load a save

    Start Satisfactory and load a save as host. The bridge starts and arms automatically when the world is ready.

Get the chaos.16 build

If you need this build manually, you can download chaos.16 for Windows Steam. First install SML in the intended profile through SMM, then close the game. In Steam, open Satisfactory’s Manage → Browse local files. Back up any existing FactoryGame/Mods/FactoryLive folder outside the Mods folder. Extract the ZIP’s FactoryLive folder into FactoryGame/Mods. Check that FactoryLive/FactoryLive.uplugin is directly inside Mods under that path. A profile change in SMM can replace a manual installation.

Launch the game, load a save as host, then follow the guide for your streaming app. Try Turn Around first. If the Pioneer turns, your chat integration is reaching this world.

Connect your stream

  • Lumia Stream for ready-made chat commands and Twitch rewards.
  • Streamer.bot for your own commands, alerts, and rewards.
  • HTTP webhooks for other local tools.

Choose an effect

Spawn a single creature or a wave, drop Nobelisks, turn the Pioneer around, or make them drop equipment. See preset IDs.

If effects don’t start

Check that SMM has Mods on and that the game’s Mods screen shows 0.9.0-chaos.16. Close any older standalone Factory Live bridge before restarting the game.
