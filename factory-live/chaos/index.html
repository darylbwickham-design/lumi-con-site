Install and arm the bridge

  1. Install the mod

    Use a SML 3.12 profile and a copy of your save. Close Satisfactory and extract the Windows mod ZIP into FactoryGame\Mods\FactoryLive in the game installation. The descriptor FactoryLive.uplugin should be directly inside that folder.

  2. Start the bridge

    Extract the bridge ZIP into its own folder. Run node bridge.mjs serve there. A fresh Chaos bridge uses port 37129 and writes its link under %LOCALAPPDATA%\FactoryLiveChaos. To carry over a custom setup, keep its port, link credentials, and mappings. Add equipment-drop from the new default config.

  3. Load the save and arm

    Launch your Satisfactory profile and load the save. Once the pioneer is ready, use a second PowerShell window in the bridge folder.

    node bridge.mjs status
node bridge.mjs arm

node bridge.mjs disarm clears queued work and cancels undetonated drops. The game still saves your living creatures and kill history. A respawn clears pending effects and holds new effects for five seconds after the game's respawn transition.

Lumia Stream and Streamer.bot

Install Factory Live Chaos 1.3.0 under Settings → Plugins → Installed → Install Manually. Use the plugin download above for the latest actions. Add Mob Chaos, Nobelisk Chaos, or Drop Random Equipment directly to a chat command, alert, or Twitch reward.

For a specific creature or explosive, pick Spawn Hog, Spawn Spitter, Spawn Stinger, Spawn Crab Hatcher, or Drop Nobelisk. Choose the tier where available and set Quantity and Multiplier. If you already use the regular Factory Live plugin with this bridge, upgrade it in place to 1.2.0 for the same actions. Lumia direct action setup

In Streamer.bot, add the supplied integrations/StreamerBotWebhook.cs as an Execute C# Code sub-action. Set Preset to the ID in the table, then bind your event. Set any price or permissions on the alert or chat platform.

equipment-drop puts one item from the pioneer's equipment slots on the ground as a normal pickup. It requires a living pioneer on foot on solid ground. The default cooldown is 60 seconds.

StreamElements webhook

On the game PC, connect StreamElements to Lumia Stream. In Lumia's StreamElements tip alert, add an outbound API → POST action. Set the URL to http://127.0.0.1:37129/v1/trigger using the port in your link file, and use the headers below. To use a named preset, you can add the Chaos plugin action to the same alert. Lumia alert guide · Lumia outbound actions

StreamElements cloud chat commands use $(customapi) through a remote GET proxy that cannot set authorization headers. For chat triggers, configure a chat command in Lumia or Streamer.bot on the game PC. StreamElements request limits

Request headers

Content-Type: application/json
Authorization: Bearer YOUR_WEBHOOK_TOKEN

Read the webhookToken in %LOCALAPPDATA%\FactoryLiveChaos\link.json. Keep the bridge on loopback and the token in the local action.

Choose a variant and quantity

{"entityId":"spitter","variant":7,"qty":24}

This requests 24 Aquatic Alpha Spitters. Use a numeric variant and a whole-number qty. Direct requests share the queues and limits with named presets.

Or use a preset

{"preset":"equipment-drop"}

Use one request format per event. Add an optional eventId and reuse it when retrying that event. HTTP 202 means the request entered the queue. HTTP 409 means the game or effect is unavailable, and HTTP 429 means a cooldown, queue limit, or busy lane applies.

GET /v1/presets with the same authorization header returns the configured presets and variant list. Download the default catalog
