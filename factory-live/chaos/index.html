Install and start

Install the version for your game build from Factory Live on ficsit.app, then load a save as host. The bundled bridge starts and arms automatically. If you used the old standalone bridge, close it before launching Satisfactory.

Faster respawns in crowded saves

When you right-click to respawn, Factory Live spreads creature sight updates across frames. With 1,763 tracked mobs alive, the longest pauses in two single-player tests were 1.06 seconds and 0.53 seconds. On the previous preview, each test had a pause over 50 seconds.

Factory Live 0.9.8 keeps the same preset IDs and named mob endpoints. Use the changelog for fixes and compatibility details.

Connect your stream

Use the Lumia Stream guide for bundled commands and Twitch rewards, or the Streamer.bot guide for preset, variant, bounce, and operator actions.

HTTP webhooks

Use the port and webhookToken from %LOCALAPPDATA%\FactoryLiveChaos\link.json. The default base URL is http://127.0.0.1:37129. Send Authorization: Bearer <webhookToken>. Use Content-Type: application/json for POST requests.

  • GET /v1/connection checks whether the game is connected, ready, and armed.
  • GET /v1/presets lists preset IDs and creature variants.
  • GET /v1/mobs lists named endpoints and shows which creatures your world can spawn.
  • POST /v1/trigger queues an effect.
  • POST /v1/hooks/pioneer-pop queues a bounce. Choose small, standard, high, 5x, or 20x.

Request a group

Send {"qty":1,"multiplier":5} to POST /v1/mobs/crab-hatcher for five hatchers in one group. Quantity counts base placements; the multiplier counts creatures per successful placement, including the first. A blocked base keeps its multiplier while queued. For three groups of five, set qty to 3. Whole-number multipliers from 1 to 100 work on hostiles and the Chaos preset. Wildlife is available through individual endpoints.

Keep the token on the host PC. A cloud chatbot needs a local integration such as Streamer.bot or Lumia to reach this loopback address. HTTP 409 means the action is unavailable in the current state; check the response and host readiness. On 429, allow the cooldown or queue to clear.

Example trigger requests

{"preset":"nobelisk-chaos"}
{"entityId":"stinger","variant":2,"qty":1}
{"strength":"20x"}

Send the first two bodies to /v1/trigger for !nukem or one Elite Gas Stinger. Send the third to /v1/hooks/pioneer-pop for the Fall Damage Express bounce. HTTP 202 confirms that the bridge queued it. If you retry the same redeem, reuse its eventId.

Keep viewer waves small

For a gentler Twitch reward, use a direct spawn action with one of these base quantities. The stream multiplier then scales each successful placement. For example, a base quantity of 3 at 8× requests 24 creatures.

In Lumia, pick a Spawn action for the creature and set Quantity to the suggested base and Multiplier to 1. In Streamer.bot, use the small-wave examples from the action pack.

If you want every call to the preset to use the smaller quantity, copy FactoryGame/Mods/FactoryLive/Bridge/bridge.config.json to %LOCALAPPDATA%\FactoryLiveChaos\bridge.local.json while the game is closed. Keep the existing local override if you already have one. In the local copy, set the port to the port in the neighboring link.json and edit the six preset count values. The bridge reads the file when the next world loads.

Recover spawned mobs

Mob recovery removes Factory Live’s tracked creatures, corpses, and hatchlings in batches. It clears pending effects and holds new redeems until cleanup finishes. The bridge keeps its current armed state. Native wildlife stays in the world.

FactoryLive.RecoverMobs confirm

Run the command from the host’s game console, or send POST /v1/recover-mobs with Authorization: Bearer <gameToken> from the host PC. Use the Streamer.bot operator examples to put recovery on a private hotkey.
