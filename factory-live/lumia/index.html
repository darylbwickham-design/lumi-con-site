Factory Live setup

Lumia Stream setup

Install the Factory Live plugin and choose effects directly from Lumia’s action picker. The plugin finds the bridge automatically on the PC hosting Satisfactory.

Install the plugin

  1. Use Lumia Stream 9.4 or later in the 9.x series. Tier, quantity, and multiplier require Factory Live Chaos Bridge 0.9.0-chaos.3 or later. Install the matching Windows mod and bridge on the same PC. The regular Bridge 0.8.5 still works with the original preset actions.
  2. Choose the download for your bridge. A fresh Chaos Bridge setup uses Factory Live Chaos 1.3.0 and reads %LOCALAPPDATA%\FactoryLiveChaos\link.json. The regular edition, Factory Live 1.2.0, uses %LOCALAPPDATA%\FactoryLive\link.json. If your existing plugin already connects to your bridge, upgrade that same edition to carry over your actions.
  3. In Lumia, open Settings → Plugins → Installed → Install Manually and select your downloaded .lumiaplugin file.
  4. Confirm the install in Lumia. Enable Factory Live on the Installed tab and connect it if prompted. It reads the bridge’s local link automatically. If you start the bridge after installing the plugin, reconnect Factory Live once the PowerShell window says it’s listening.
  5. For a dry check, add Factory Live → Check Bridge to a temporary chat command and click Test on that command’s row. A popup should report Bridge connected. This check is safe with the game closed or the bridge disarmed.

Factory Live is distributed here as a manual download. Use the Installed tab for this package. Lumia’s official Plugin SDK documentation

Choose a creature, tier, and quantity

  1. Open Actions inside a Twitch reward, chat command, or alert. Pick Factory Live and select Spawn Hog, Spawn Spitter, Spawn Stinger, Spawn Crab Hatcher, or Drop Nobelisk.
  2. Choose the Tier, Variant, or Type where shown. Enter the base Quantity as a positive whole number.
  3. Leave Multiplier at 1, enter a positive number, or use the field’s variable picker to insert a numeric value from the event. For example, choose Spawn Hog → Alpha with quantity 20 and multiplier 1.5 to queue 30 Alpha Hogs.

The plugin rounds the scaled quantity to the nearest whole number. Each action can request up to 300 creatures, 32 conventional Nobelisks, or one direct Nuke. The bridge applies the game’s capacity and cooldown. Use Trigger Preset → Nuclear Carpet Bomb for a timed five-Nuke wave.

Mob Chaos, Nobelisk Chaos, Drop Random Equipment, and Turn Pioneer Around also appear as direct actions. The Chaos guide lists every tier and variant.

Create a Twitch channel point reward

This example sets up Surprise Me for 1 point with a 60-second cooldown.

  1. Connect the Twitch broadcaster account in Settings → Connections and allow Lumia to manage channel point rewards. Then go to Commands → Twitch Points → Add Command.
  2. In the command’s first step, open Actions. Find Factory Live in the picker, add Trigger Preset, and choose Surprise Me. Save the action.
  3. Expand Name & description. Enter Factory Live Surprise Me as the title and set Points to 1. For the description, use Roll for a 180° turn or an Elite Stinger.
  4. Expand Advanced Command options, set Global cooldown to 60 seconds, and click Complete and Save. Check that the reward is enabled and says Linked in the Twitch Points list.
  5. Keep the reward disabled or paused while setting up if viewers are active. When you’re ready, load a test save, wait for game.ready, arm the bridge, and use Test once on the reward row. Look for the effect in game or check the queue if it was delayed.

Bind a chat command or alert

  • Chat. In Commands → Chat Commands → Add Command, enter turn as the command name and add Factory Live → Turn Pioneer Around. Set the chat permissions and cooldown, save, then type !turn in chat.
  • Alerts. In Lumia’s Alerts section, edit an event such as a raid. Add Factory Live → Trigger Preset → Creature Roulette to the event’s actions. A matching alert can queue one wave.
  • Custom bridge presets. Choose Trigger Custom Preset for a name you added under presets in your bridge config. Enter the exact name as fixed text in the action.

Use factory_live_result for the outcome, factory_live_quantity for the accepted count from a direct action, or factory_live_selected_preset for the effect picked by a random reward. queued means the bridge accepted the request. The standalone Chaos plugin uses the factory_live_chaos_ prefix.

Upgrade an existing Lumia reward

Install the new version over the matching plugin ID. Existing Trigger Preset and Trigger Custom Preset bindings carry over. On Bridge 0.8.5, use those preset actions for creature and Nobelisk rewards.

On Chaos Bridge, open the reward’s edit pencil in Twitch Points. Replace its Factory Live action with the corresponding direct action. Copy the original tier and quantity, leave the multiplier at 1, and save the same reward to keep its Twitch link, title, and points. Keep preset actions for randomized effects or timed waves such as Nuclear Carpet Bomb.

Troubleshooting

Factory Live is missing from the action picker

Check that the plugin appears and is enabled in Settings → Plugins → Installed. Start the bridge before connecting the plugin. Reopen the editor after enabling it.

A direct action reports variant_bridge_upgrade_needed

Use the Chaos bridge with its matching mod to send a tier and quantity, or select a supported preset with the bridge you have.

Check Bridge reports disconnected or disarmed

Use the popup to tell the local bridge from the game connection. Start the bridge if it’s unreachable. If the bridge is connected, load a save as host and unpause. From the bridge folder, run node bridge.mjs status, then node bridge.mjs arm once game.ready is true.

The action ran but no effect appeared

Check the result variable and the bridge’s status. A cooldown, full queue, game frame-time pause, or unavailable player action can block a request. A creature wave may take time to complete. Turn Around requires the pioneer to be on foot and able to look around.
