Lumia Stream setup

Install the plugin

  1. Use Lumia Stream 9.4 or later in the 9.x series and Factory Live Bridge 0.8.0. Set up the Windows mod and bridge on the same PC. Start the bridge in PowerShell and leave it running.
  2. Download FactoryLive_Lumia_1.0.0.lumiaplugin above. In Lumia, open Settings → Plugins → Installed → Install Manually and select the file as downloaded.
  3. Confirm the install in Lumia. Enable Factory Live on the Installed tab and connect it if prompted. It reads the bridge’s local link automatically. If you start the bridge after installing the plugin, reconnect Factory Live once the PowerShell window says it’s listening.
  4. For a dry check, add Factory Live → Check Bridge to a temporary chat command and click Test on that command’s row. A popup should report Bridge connected. This check is safe with the game closed or the bridge disarmed.

Factory Live is distributed here as a manual download. Use the Installed tab for this package. Lumia’s official Plugin SDK documentation

Create a Twitch channel point reward

This example sets up Surprise Me for 1 point with a 60-second cooldown.

  1. Connect the Twitch broadcaster account in Settings → Connections and allow Lumia to manage channel point rewards. Then go to Commands → Twitch Points → Add Command.
  2. In the command’s first step, open Actions. Find Factory Live in the picker, add Trigger Preset, and choose Surprise Me. Save the action.
  3. Expand Name & description. Enter Factory Live Surprise Me as the title and set Points to 1. For the description, use Roll for a backpack shuffle, a quick turn, or an Elite Stinger.
  4. Expand Advanced Command options, set Global cooldown to 60 seconds, and click Complete and Save. Check that the reward is enabled and says Linked in the Twitch Points list.
  5. Keep the reward disabled or paused while setting up if viewers are active. When you’re ready, load a test save, wait for game.ready, arm the bridge, and use Test once on the reward row. Look for the effect in game or check the queue if it was delayed.

Bind a chat command or alert

  • Chat. In Commands → Chat Commands → Add Command, enter shuffle as the command name and add Factory Live → Trigger Preset → Backpack Shuffle. Set the chat permissions and cooldown, save, then type !shuffle in chat.
  • Alerts. In Lumia’s Alerts section, edit an event such as a raid. Add Factory Live → Trigger Preset → Creature Roulette to the event’s actions. A matching alert can queue one wave.
  • Custom bridge presets. Choose Trigger Custom Preset for a name you added under presets in your bridge config. Enter the exact name as fixed text in the action.

Optional action results for follow-up messages or overlays include factory_live_result (for example, queued or cooldown), factory_live_status, and factory_live_selected_preset. The last one tells you what a random reward selected. queued means the bridge accepted the request.

Upgrade an existing Lumia reward

Open the reward’s edit pencil in Twitch Points. Add Factory Live → Trigger Preset with the same effect, remove its previous Factory Live API or Code action, then save. This keeps the same Twitch reward, title, and cost. If Streamer.bot also listens for that reward, remove its Factory Live mapping for that reward before testing.

Troubleshooting

Factory Live is missing from the action picker

Check that the plugin appears and is enabled in Settings → Plugins → Installed. Run Bridge 0.8.0 before connecting the plugin. Reopen the editor after enabling it.

Check Bridge reports disconnected or disarmed

Use the popup to tell the local bridge from the game connection. Start the bridge if it’s unreachable. If the bridge is connected, load a save as host and unpause. From the bridge folder, run node bridge.mjs status, then node bridge.mjs arm once game.ready is true.

The action ran but no effect appeared

Check the result variable and the bridge’s status. A cooldown, full queue, game frame-time pause, or unavailable player action can block a request. A queued creature wave can take time to complete. For Shuffle and Turn Around, the pioneer needs to be able to use the backpack or look around.
