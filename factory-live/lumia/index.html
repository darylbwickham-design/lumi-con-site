Lumia Stream setup

Set up Satisfactory Stream Integration with ready-made chat commands and Twitch reward templates.

Get Factory Live in SMM Download Lumia plugin 1.7.5
Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. Keep Disarm Bridge on a private Lumia button. It clears queued effects; creatures already in the world stay there.

Set up the game and plugin

  1. Install the game mod

    Install Factory Live through Satisfactory Mod Manager. Load a save as host so the bridge can start.

  2. Install the Lumia plugin

    In Lumia Stream 9.4 or later, open Settings → Plugins and find Satisfactory Stream Integration. To install the download above, go to Installed → Install Manually, open the .lumiaplugin file, and enable the plugin. Use Factory Live 0.9.8 for both new bounce strengths.

  3. Import the commands you want

    Version 1.7.5 includes two chat commands and 19 Twitch reward templates. When Lumia asks to install bundled commands, choose Install. Select Chat Commands for !chaos and !nukem. Use Use file target (Twitch Points Commands) for rewards. Skip any you already have.

Set up Twitch rewards

  1. Connect your Twitch channel in Settings → Connections.
  2. Open Commands → Twitch Points, then click Sync with Twitch. Create or link the rewards you want.
  3. Check prices and permissions before enabling rewards. Prices and cooldowns are yours to change.
  • Boing Voyage (5x Bounce) launches the Pioneer at 5× force. The template costs 25 points and has a 15-second shared cooldown.
  • Fall Damage Express (20x Bounce) launches the Pioneer at 20× force. The landing can be fatal. The template costs 100 points and has a 30-second shared cooldown.

The two bounce strengths are fixed. See the smaller creature wave setup if you use the stream multiplier with your mob rewards.

Use the chat commands

The streamer and moderators can type !nukem for the 250-Nobelisk fireworks show or !chaos for a large creature event. The default Chaos preset requests up to 1,200 hostile placements. !chaos 10 requests ten mobs at each placement, up to 12,000 in total. Keep this command moderator-only.

Set up the stream multiplier

The multiplier starts at 1×. Each use of the +1 multiplier reward increases it by one, and creature rewards use the current multiplier in addition to their own settings. A base quantity of 5 at 3× requests 15 creatures. Fifteen increases reach 16×.

  1. Import the bundled multiplier reward. Connect it to a Twitch channel-point reward, set its price to 50 points, and set Twitch’s maximum redemptions per stream to 15. Sync the reward with Twitch.

  2. Add the plugin’s Reset Stream Multiplier action to Lumia’s Twitch Stream Live alert so a new stream starts at 1×. The bundled reward also tracks the session when its session-start variable is available.

  3. The action sends the current multiplier is now X to Twitch chat. Connect the Lumia chatbot to Twitch so it can post. For overlays, the variable is {{factory_live_stream_multiplier}}.

The multiplier does not make every effect a creature spawn. Large numbers and repeated redeems can overwhelm the game.

Pioneer death alert and counter

Enable the plugin’s Pioneer Death alert in Lumia and add a chat action with the pioneer has died {{factory_live_death_count}} times. The count can be reset with the plugin’s Reset Pioneer Death Count action. Put that action on a broadcaster-only command such as !resetdeaths, then save it.

Add your own effect

Edit a command, reward, or alert and open Actions → Satisfactory Stream Integration. Try Spawn Hog, choose a tier, and set a quantity. For a first reward, use Quantity 1 and Multiplier 1. To create a hatcher group, select Spawn Crab Hatcher, Quantity 1, Multiplier 5. Save the action. This requests one central hatcher and four around it, each about eight metres from the center. Mobile hostiles start together and can move apart.

Check or pause the bridge

Use Check Bridge to see whether the world is ready. Disarm Bridge clears queued effects. Use Arm Bridge to resume. Keep the mob recovery command private for clearing creatures already spawned by Factory Live.

Update an existing !chaos command

Install version 1.7.5 over your existing Satisfactory Stream Integration plugin to keep its action bindings. In Commands → Chat Commands, edit !chaos. Under Actions → Start of Command, select Mob Chaos. Enter {{message}} under Mobs per placement and save. Keep your moderator permissions and cooldown. With no number, the command uses one mob per placement. Whole numbers from 1 to 100 are supported.
