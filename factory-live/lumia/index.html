Lumia Stream setup

Set up Satisfactory Stream Integration with two chat commands and 16 Twitch reward templates.

Get Factory Live in SMM Download the Lumia plugin
Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. Keep Disarm Bridge on a private Lumia button. It clears queued effects; creatures already in the world stay there.

Set up the game and plugin

  1. Install the game mod

    Follow the Satisfactory Mod Manager steps. Load a save as host so the bridge can start.

  2. Install the Lumia plugin

    In Lumia Stream 9.4, go to Settings → Plugins and search Marketplace for Satisfactory Stream Integration. Enable the plugin. Version 1.6.1 supports chat multipliers. If Marketplace offers an earlier version, download the plugin above, then go to Installed → Install Manually and select the downloaded file.

  3. Import the commands you want

    When Lumia asks to install bundled commands, choose Install. Select Chat Commands for !chaos and !nukem. For rewards, select Use file target (Twitch Points Commands). Skip any duplicates.

Set up Twitch rewards

  1. Connect your Twitch channel in Settings → Connections.
  2. Open Commands → Twitch Points, then click Sync with Twitch. Create or link the rewards you want.
  3. Check the prices. Turn Around starts at 100 points, Creature Roulette at 250, and Nuclear Carpet Bomb at 1,000. You can edit any price in Lumia.

Use the chat commands

The streamer and moderators can type !nukem for the 250-Nobelisk fireworks show or !chaos for a large creature event. The default Chaos preset requests up to 1,200 hostile placements. !chaos 10 requests ten mobs at each placement, up to 12,000 in total. Keep this command moderator-only.

Add your own effect

Edit a command, reward, or alert and open Actions → Satisfactory Stream Integration. Try Spawn Hog, choose a tier, and set a quantity. For a first reward, use Quantity 1 and Multiplier 1. To create a hatcher group, select Spawn Crab Hatcher, Quantity 1, Multiplier 5. Save the action. This requests one central hatcher and four around it, each about eight metres from the center. Mobile hostiles start together and can move apart.

Check or pause the bridge

Use Check Bridge to see whether the game is ready. Keep Disarm Bridge on a private button to stop new effects and clear the queue. Use Arm Bridge to resume.

Update an existing !chaos command

Install Satisfactory Stream Integration version 1.6.1 over your existing plugin to keep its action bindings. In Commands → Chat Commands, edit !chaos. Under Actions → Start of Command, replace the old Chaos preset action with Mob Chaos. Enter {{message}} under Mobs per placement and save. Keep your moderator permissions and cooldown. With no number, the command uses one mob per placement. Whole numbers from 1 to 100 are supported.
