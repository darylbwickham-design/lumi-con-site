Lumia Stream setup

Set up Satisfactory Stream Integration with two chat commands and 16 Twitch reward templates.

Get Factory Live in SMM Download the Lumia plugin

Set up the game and plugin

  1. Install the game mod

    Follow the Satisfactory Mod Manager steps. Load a save as host so the bridge can start.

  2. Install the Lumia plugin

    In Lumia Stream 9.4, go to Settings → Plugins. Look for Satisfactory Stream Integration in Marketplace. To use the download above, go to Installed → Install Manually and select the file. Enable the plugin.

  3. Import the commands you want

    When Lumia asks to install bundled commands, choose Install. Select Chat Commands for !chaos and !nukem. For rewards, select Use file target (Twitch Points Commands). Skip any duplicates.

Set up Twitch rewards

  1. Connect your Twitch channel in Settings → Connections.
  2. Open Commands → Twitch Points, then click Sync with Twitch. Create or link the rewards you want.
  3. Check the prices. Turn Around starts at 100 points, Creature Roulette at 250, and Nuclear Carpet Bomb at 1,000. You can edit any price in Lumia.

Use the chat commands

The streamer and moderators can type !nukem for the 250-Nobelisk fireworks show or !chaos for a large creature event. Start with a small reward if you’re testing for the first time.

Add your own effect

Edit a command, reward, or alert and open Actions → Satisfactory Stream Integration. Try Spawn Hog, choose a tier, and set a quantity. Keep the multiplier at 1 to use that quantity.

Check or pause the bridge

Use Check Bridge to see whether the game is ready. Keep Disarm Bridge on a private button to stop new effects and clear the queue. Use Arm Bridge to resume.

Upgrading from Factory Live 1.3.1

Install 1.5.0 over the existing Factory Live plugin to keep its action bindings. Close the standalone bridge before restarting the game.
