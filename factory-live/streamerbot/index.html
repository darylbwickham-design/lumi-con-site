Set up your first reward

  1. Install Factory Live through Satisfactory Mod Manager. Run Streamer.bot as the same Windows user, connect your Twitch broadcaster account, then load a save as host. The bridge starts and arms as the world becomes ready.

  2. In Platforms → Twitch → Channel Point Rewards, create a reward, or pick an existing one. In Actions, create an action and add a Twitch Reward Redemption trigger for that specific reward. Connect each reward in one app so it fires once.

  3. Extract the ZIP and open a matching .cs file in a text editor. Paste the entire file into Core → C# → Execute C# Code. Click Find Refs if needed, then Compile and Save and Compile.

  4. For a small first test, paste gentle/hog-wild.cs. It queues three basic hogs at 1×. Check Action Queues → Action History for factoryLiveStatus and factoryLiveResult. A 202 response means the bridge accepted the request for processing.

The scripts read the port and token from link.json. Keep this file private. You can download Trigger.cs separately and edit the four settings at the top to create a new action.

The ZIP includes a preset-independent C# action for each variant under variants/. The game reports which creatures it can currently spawn at GET /v1/mobs. GET /v1/presets lists the active preset configuration.

Match the +1 multiplier reward

Create a 50-point Twitch reward with a maximum of 15 redemptions per stream. Paste IncreaseMultiplier.cs into its action and use a non-concurrent action queue. It starts at 1×, increases to 16×, and posts the current multiplier is now X.

Put ResetMultiplier.cs on Twitch Stream Online, or on a broadcaster-only !resetmulti command for manual resets. Lumia keeps its own multiplier and death count.

Moderator commands and Bits

In Commands, create !chaos in Starts With mode and limit it to the broadcaster and moderators. Attach a Command Triggered trigger to an action using examples/chaos-chat.cs. !chaos 10 stacks 10 creatures per placement. Missing or invalid input uses 1×, and the script caps typed values at 100×.

For !nukem, use an exact-match command with presets/nobelisk-chaos.cs, which runs the 250-Nobelisk sequence at 1×. For other chat commands, use the matching preset file in the table.

To mirror the Bits effects, add a Twitch Cheer trigger to an action using presets/nobelisk-chaos.cs or examples/chaos-fixed.cs. Set only Max to 100 for Nukem and 300 for Chaos. Streamer.bot uses an exact match when only Max is set. These react to cheers in chat. Cheer trigger reference

In Streamer.bot, create a repeating two-second timer with no line minimum, then add a Timed Action trigger to DeathCounter.cs. It posts the pioneer has died X times when it sees a new death ID. Paste ResetDeaths.cs into a separate broadcaster-only reset action. The timer can miss deaths while it is offline or between polls.

If an action fails

  • 401 unauthorized means the request used the wrong token or copied an old link file. Run Streamer.bot under the same Windows user as the game.
  • 409 game_not_armed_or_ready means you need to load a save as host and check the bridge status. Use the Arm action if you disarmed it.
  • 429 cooldown or queue_full means the bridge is pacing effects or its queue is full. Let it catch up before testing again.
  • 400 stack_hostiles_only means a wildlife action tried to use a multiplier above 1×.
