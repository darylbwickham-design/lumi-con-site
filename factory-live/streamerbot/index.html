Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. You can use Disarm Bridge in the Lumia plugin to stop new effects and clear the queue. Creatures already in the world stay there.

Create an action

  1. Load a save

    Run Satisfactory and Streamer.bot on the same Windows PC. The Factory Live bridge starts when the host save is ready.

  2. Add the script

    In Streamer.bot, create an action. Add an Execute C# Code sub-action, open its editor, then paste the Factory Live script from the link above.

  3. Pick a preset

    In the constants near the top of the script, set Preset to turn-around for a small first test or nobelisk-chaos for the fireworks show. Compile and save the action, then run it from Streamer.bot.

Make a five-hatcher reward

Duplicate the working action and name it Five Hatchers. In its C# sub-action, set Mob = "crab-hatcher", Quantity = 1, and Multiplier = 5. Compile and save. Link the reward below. A nonempty Mob selects that creature; an empty Mob runs the named preset. Set Multiplier back to 1 for wildlife and Nobelisks.

Connect a Twitch reward

Add a Twitch → Channel Reward → Reward Redemption trigger to the action, then choose your reward.

Connect a chat command

Create a command in Streamer.bot and add its Command Triggered trigger to the action. For !nukem or !chaos, limit access to the broadcaster and moderators.

If the action fails

Load a save as host, then check the factoryLiveResult argument. For custom HTTP calls, see the webhook endpoints and examples.
