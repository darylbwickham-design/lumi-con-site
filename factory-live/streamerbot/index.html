Crash warning

Repeated waves and high multipliers can freeze or crash Satisfactory, especially during respawn. Make a separate save before enabling chat. You can use Disarm Bridge in the Lumia plugin to stop new effects and clear the queue. Creatures already in the world stay there.

Create a Twitch reward action

  1. Connect Twitch in Streamer.bot. Run the game and Streamer.bot on the same Windows PC, then load a save as host.
  2. Create or select a Twitch channel-point reward, create an action, then add a Twitch → Channel Point Reward Redemption trigger for that reward.
  3. Add a Core → C# → Execute C# Code sub-action. Paste Trigger.cs, set Preset near the top to the desired ID from the preset table, leave Mob empty, compile and save.
  4. Repeat for each reward, choosing its own preset, cost and cooldown. The complete mapping and setup guide covers every preset and creature endpoints. These are copy-and-paste scripts, not an import.

A response of accepted means queued, not necessarily spawned. The action reads the bridge token automatically; keep it private.

Match the +1 multiplier reward

Create a Twitch reward costing 50 points with a maximum of 15 redemptions per stream. Attach an action containing IncreaseMultiplier.cs, and use a non-concurrent action queue so simultaneous redemptions are counted. It starts at 1× and reaches 16× after fifteen uses, announcing each increase in chat.

Attach ResetMultiplier.cs to Twitch Stream Online to reset to 1× at the start of each stream. The other example reward scripts use this value. Lumia and Streamer.bot keep separate multiplier and death counts: connect each reward to one app only or it will fire twice.

Moderator chat commands

For !chaos, make a moderator-only command and attach a copy of Trigger.cs with Preset = "chaos-mode" and UseChatMultiplier = true. !chaos 10 uses 10 per placement; no valid number uses 1. For !nukem, use Preset = "nobelisk-chaos", UseChatMultiplier = false and UseStreamMultiplier = false, matching Lumia's fixed 1× command.

Death alert

Run DeathCounter.cs from a recurring two-second timer to count observed deaths and send the pioneer has died X times. Put ResetDeaths.cs on a private reset command. Polling is best effort: deaths while offline or multiple deaths between polls can be missed, and a recent death may be counted on first connection.

If an action fails

Load a save as host and check the Streamer.bot log for compilation or bridge errors. Check Twitch connectivity if chat messages do not appear. For direct HTTP calls, see the webhook endpoints and examples.
