Quick setup

Connect the two PCs.

1

Install the plugin

Install the .lumiaplugin file in Lumia Stream on the stream PC.

2

Configure Lumia

Enable Lumia's local API, then enter its token in the plugin. Choose LAN access and set a Dashboard Password.

3

Open the companion

Launch the portable app on the game PC and enter the stream PC address, plugin port 39242, and Dashboard Password.

4

Build and control

Use the dashboard, Command Builder, alerts, lights and Pulse Weaver while Lumia handles execution on the stream PC.

Network: both computers should be on the same trusted local network. Allow the plugin dashboard port through the stream PC firewall for private networks. The Lumia API token stays on the stream PC.
