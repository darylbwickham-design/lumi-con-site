Your stream has a co-host

Pulse the Tiny Bot

Tiny robot, strong opinions. Say “Hey Pulse” in chat and watch him answer, remember returning viewers, and react to the moments that matter.

Windows companion 1.5.0 Lumia plugin 1.3.6

Early release for Windows. Download both files. Pulse needs Node.js 22 or newer and Lumia Stream 9 or newer for live integration.

What Pulse does

  • Answers viewers who address him through Lumia’s incoming chat feed.
  • Uses local AI for banter, with mood changes and optional viewer memory.
  • Performs an animated facecam with 20 expressions, 17 gestures, and 14 silent performance presets.
  • Speaks through Lumia TTS. An optional mixer connection can drive the mouth and captions from audio activity.

Get him on stream

  1. Extract the companion ZIP. Run Setup Free AI.cmd if you want the optional local AI model.
  2. Run Start Pulse Bot (Lumia Plugin).cmd and open http://127.0.0.1:3210/ on your stream PC.
  3. In Lumia, open Plugins → Installed → Install Manually, then import the plugin file.
  4. In the plugin settings, enter the bridge key from your Pulse dashboard and your Lumia local API token. The ZIP includes the full guide under lumia-plugin/SETUP.md.

Your settings, viewer memory and sign-in stay on your PC. Twitch posting is optional and requires connecting your own bot account.
